# Catalog calibration v1 — superseded historical run

This historical pack used Portuguese. It was introduced in local commit `7c4feea` and is superseded by the [English v2 pack](../calibration/catalog-v2/README.md) and its [verification report](catalog-calibration-v2.md).

The old source files remain in Git history. The four original local runs and their immutable cases/outputs remain unchanged; their results are retained in `catalog-calibration-v1.json`. A link to an old experiment therefore still shows the original Portuguese evidence. No human approvals or live-model evaluation were claimed.

The old controls verified 480 metric decisions across 40 cases and 80 executions, with 25 deliberately faulty records detected. Use v2 for all further work.
